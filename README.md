📘 Smart Attendance System
🧭 Overview

A Java-based system that simplifies student attendance logging using OOP principles and database persistence.

---

📦 Features

✔ Add Students & Courses
✔ Mark Attendance
✔ View Records
✔ JDBC Database Operations
✔ OOP Modular Design

---

🧠 Tech Stack

Java 17+

JDBC

MySQL / MariaDB

JavaFX or Swing

Maven / Gradle

---

📁 Project Structure
src/main/java/
    model/
    dao/
    controller/
    ui/
database/
docs/

---

🗄️ Database Setup

Create DB

Execute schema.sql

Update DBConfig credentials

---

▶️ How to Run
git clone <repo>
mvn clean install
run App.java
